# 电磁感应

**开场谜题：手机放在无线充电板上，两者之间没有任何导线相连，电是怎么跑进手机的？**（答案在最后）

## 第 1 步：反过来想

上一课学了：**电流能产生磁场**。

1831 年，法拉第想：那反过来，**磁场能不能产生电流？**

他把一个线圈接上电流表，把磁铁放进线圈里。结果：

- 磁铁**静止**放在线圈里：电流表**不动**
- 磁铁**插进去**的那一下：电流表**偏转**
- 磁铁**拔出来**的那一下：电流表**反向偏转**
- 插得**越快**，偏转**越大**

## 第 2 步：关键是"变化"

> **穿过线圈的磁场发生变化，线圈里就会产生电压（感应电动势），接通了就有电流。这叫电磁感应。**

重点是**变化**，不是**有没有**。磁场再强，只要不变，就不产生电压。

## 第 3 步：磁通量：穿过线圈的磁感线有多少

为了说清"穿过线圈的磁场"，引入**磁通量 Φ**：

> **Φ = B × A**（磁感应强度 × 线圈面积，磁场垂直穿过线圈时）

单位**韦伯（Wb）**，1 Wb = 1 T × 1 m²。

直观理解：Φ 就是**穿过线圈的磁感线的根数**。磁场越强、线圈越大，穿过的线越多。

让 Φ 变化的办法有很多，**任何一种都能产生感应电压**：

| 办法 | 例子 |
|---|---|
| 磁铁靠近 / 远离线圈（B 变） | 法拉第的实验 |
| 旁边线圈的电流变化（B 变） | **变压器** |
| 线圈在磁场里转动（穿过的有效面积变） | **发电机** |

## 第 4 步：电压有多大：法拉第定律

> **感应电压 = 线圈匝数 N × 磁通量的变化率（ΔΦ ÷ Δt）**

例：线圈 100 匝，磁通量在 0.1 秒内从 0.002 Wb 降到 0：

```text
ΔΦ / Δt = 0.002 Wb ÷ 0.1 s = 0.02 Wb/s
电压 = 100 × 0.02 = 2 V
```

三个规律，从公式直接看出来：

- **变得越快**，电压越大（Δt 越小）
- **匝数越多**，电压越大（每一圈都贡献一份电压，串起来相加）
- **不变**，就没有电压（ΔΦ = 0）

"变化率"就是微积分直觉那一课讲的**斜率**：不看 Φ 是多少，只看它变得有多快。

## 第 5 步：方向呢？

磁铁插进去和拔出来，电流方向相反。具体往哪个方向，由**楞次定律**决定，下一课专门讲。

## 揭晓谜题

充电板里有一个线圈，通的是**快速变化的交流电**（每秒十几万次）。它产生的磁场也在快速变化，穿过手机里的线圈。手机线圈里的磁通量不停变化，就感应出电压，给电池充电。**电是靠变化的磁场"隔空"传过去的。**

所以只要两个线圈对准、靠得近，就能传电；离远了，穿过手机线圈的磁感线变少，效率就急剧下降。

## 这和做硬件有什么关系

| 场景 | 和电磁感应的关系 |
|---|---|
| **发电机** | 线圈在磁场里转，Φ 不断变化，发出电 |
| **变压器** | 一个线圈的交流电变化 → 磁场变化 → 另一个线圈感应出电压；匝数比决定电压比。**直流电不变化，变压器对它没用** |
| **无线充电、NFC 刷卡** | 两个线圈之间靠变化的磁场传能量和数据 |
| **电感** | 线圈自己的电流变化，也会在自己身上感应出电压（自感），所以电感"抗拒电流变化"（§6 会讲） |
| **继电器、电机断电时的高压尖峰** | 电流突然断掉，Δt 极小，感应出很高的电压，会打坏三极管。所以线圈旁边要并一个**续流二极管** |
| **动圈麦克风** | 和喇叭反过来：声音推动线圈在磁场里振动，感应出电信号 |
| **干扰** | 大电流走线旁边的环路，会被感应出噪声，所以 PCB 上要让环路面积尽量小 |

## 三句话总结

1. **磁通量变化**，线圈里就产生感应电压；磁场不变，再强也没用
2. **电压 = 匝数 × 磁通量变化率**：变得越快、匝数越多，电压越大
3. 发电机、变压器、无线充电都靠它；电流突然断开会产生高压尖峰
