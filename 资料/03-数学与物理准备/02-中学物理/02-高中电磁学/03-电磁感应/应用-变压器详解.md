# 电磁感应的应用：变压器详解

**开场谜题：墙上插座是 220V，手机充电器输出 5V。电压是怎么"变小"的？而且充电器的输出和 220V 之间根本没有导线相连。**

## 第 1 步：长什么样

```text
        ┌─────── 铁芯（一个闭合的铁框）───────┐
        │                                    │
  ~220V ┤ ((((((( 初级线圈        次级线圈 ))) ├ 12V 输出
        │     1100 匝                 60 匝   │
        │                                    │
        └────────────────────────────────────┘
```

- 一个**铁芯**，围成一个闭合的框
- 框的一边绕**初级线圈**（接电源），另一边绕**次级线圈**（接负载）
- 两个线圈之间**没有导线相连**，各自是独立的电路

## 第 2 步：完整的因果链

```text
初级接交流电，电流不断变化
    ↓（电流产生磁场）
铁芯里的磁场不断变化
    ↓（铁芯把磁感线"圈住"，几乎全部穿过次级线圈）
次级线圈里的磁通量不断变化
    ↓（电磁感应）
次级线圈两端感应出电压
```

**铁芯的作用**：铁很容易被磁化，磁感线几乎都愿意从铁里走，就像水管把水圈在管子里。所以初级产生的磁感线，几乎全部被铁芯带着穿过次级线圈。没有铁芯，磁感线四处散开，大部分穿不过次级。

## 第 3 步：为什么匝数决定电压

关键一句话：

> **两个线圈套在同一个铁芯上，穿过它们每一圈的磁通量是同一个，变化率 ΔΦ/Δt 也是同一个。所以每一圈感应出的电压都一样大。**

把它叫做**"每匝电压"**。线圈的总电压 = 每匝电压 × 匝数（每一圈串起来相加）。

初级这边也一样：初级线圈的每一圈也被这个变化的磁通量感应出电压，这些电压加起来，正好顶住电源电压（楞次定律：对着干）。所以：

```text
每匝电压 = 电源电压 ÷ 初级匝数 = 220V ÷ 1100 匝 = 0.2 V/匝
次级电压 = 每匝电压 × 次级匝数 = 0.2 V/匝 × 60 匝 = 12V
```

写成公式：

> **V₂ / V₁ = N₂ / N₁**（电压比 = 匝数比）

- 次级匝数**少** → 电压**降低**（降压变压器，充电器、适配器）
- 次级匝数**多** → 电压**升高**（升压变压器，发电厂往外送电）

## 第 4 步：电压降了，电流呢

变压器只是传递能量，不产生能量（理想情况下几乎不损耗）：

> **输入功率 ≈ 输出功率：V₁ × I₁ ≈ V₂ × I₂**

接上面的例子，次级给负载供 12V、1A，就是 12W：

```text
初级电流 = 12W ÷ 220V ≈ 0.055A
```

**电压降低多少倍，电流就增大多少倍。** 所以降压变压器的次级线圈用**更粗**的导线，因为它要通更大的电流。

这也是远距离输电要用高压的原因：同样的功率，电压升高 100 倍，电流就减小 100 倍，导线上的发热（I²R）减小一万倍。

## 第 5 步：为什么直流不行

电池是直流，电流不变 → 磁场不变 → 磁通量不变化 → 次级**感应不出电压**。

只有接上和断开的那一瞬间有变化，次级会冒出一个短暂的脉冲，之后就没了。而且初级线圈就是一根电阻很小的导线，接在直流上几乎等于短路，会烧。

> **变压器只能变交流电。**

## 第 6 步：变压器带来的另一个好处：隔离

次级和初级之间**没有导线相连**，能量是靠磁场"隔空"过去的。所以次级这边的电路和 220V 市电是**电气隔离**的：你摸到 5V 那一侧，不会通过它触到市电。这是安全的关键，充电器里的变压器既负责降压，也负责隔离。

## 第 7 步：为什么现在的充电器那么小

老式变压器直接接 50Hz 市电，又大又重（几百克的铁疙瘩）。现在的手机充电器只有拇指大，里面也有变压器，只不过：

```text
220V 交流 → 先整流成直流 → 用开关管把它切成几十 kHz 到上百 kHz 的高频交流
          → 小变压器降压 → 再整流成直流 → 5V 输出
```

为什么频率高了，变压器就能做小？回到法拉第定律：**感应电压 = N × ΔΦ/Δt**。频率越高，变化越快（Δt 越小），同样的电压需要的磁通量就越小 → 铁芯可以更小、匝数可以更少。

这就是**开关电源**，后面电源那一章会专门讲。

## 其他应用一览

| 应用 | 怎么用的电磁感应 |
|---|---|
| **发电机** | 线圈在磁铁中间转，穿过线圈的磁通量一会儿多一会儿少，感应出交流电。发电厂、自行车灯都是它 |
| **无线充电** | 等于一个**拆成两半、没有铁芯的变压器**：充电板是初级，手机里是次级。中间隔着空气，磁感线容易散，所以要对准、靠近 |
| **NFC / 公交卡** | 卡里没电池，读卡器线圈发出变化的磁场，卡里的线圈感应出电压，给芯片供电，顺便传数据 |
| **电磁炉** | 变化的磁场直接在铁锅底感应出涡流，锅自己发热 |
| **动圈麦克风** | 声音推动线圈在磁铁旁振动，感应出电信号 |
| **电流互感器** | 大电流导线穿过一个线圈，用感应出的小电流来测量大电流，电表里常见 |

## 三句话总结

1. 变压器 = **两个线圈 + 一个铁芯**：初级的交流电产生变化的磁场，铁芯把它带到次级，次级感应出电压
2. 同一个铁芯里，**每一圈的感应电压一样**，所以**电压比 = 匝数比**；功率不变，电压降低，电流就增大
3. 只能用于**交流**；频率越高，变压器可以做得越小，这就是现代开关电源小巧的原因
