# 楞次定律

**开场谜题：一块强磁铁扔进一根竖着的铜管里，铜管不吸铁，磁铁却像掉进了蜂蜜，慢慢悠悠地飘下来。为什么？**（答案在最后）

## 第 1 步：问题是方向

上一课知道了：磁通量变化，线圈里就感应出电流。磁铁插进去和拔出来，电流方向相反。

那电流**到底往哪边流**？楞次定律一句话回答：

> **感应电流产生的磁场，总是阻碍引起它的那个磁通量变化。**

关键词是**阻碍变化**。线圈像一个"保守派"，不喜欢磁通量变，你让它变，它就产生电流来对着干。

## 第 2 步：四种情况

记口诀：**来拒去留**。

| 磁铁动作 | 穿过线圈的磁通量 | 线圈的反应 | 线圈对着磁铁的一端 |
|---|---|---|---|
| N 极**插进来** | 增加 | 不让增加 → 把磁铁**推开** | 变成 **N 极**（同极相斥） |
| N 极**拔出去** | 减少 | 不让减少 → 把磁铁**拉住** | 变成 **S 极**（异极相吸） |
| S 极插进来 | 增加 | 推开 | 变成 S 极 |
| S 极拔出去 | 减少 | 拉住 | 变成 N 极 |

知道了线圈哪端是 N 极，再用上一课的**右手螺旋定则**（拇指指 N 极，四指弯的方向就是电流方向），就得出电流方向。

所以判断方向分三步：

1. 磁通量在**增加**还是**减少**？
2. 线圈要**反着来**：增加就推开，减少就拉住，确定线圈哪端是 N 极
3. 右手螺旋定则，从 N 极推出电流方向

## 第 3 步：为什么一定是"阻碍"

假设反过来：磁铁插进来，线圈不推它，反而**吸**它。

那磁铁会被越吸越快 → 磁通量变得更快 → 感应电流更大 → 吸得更狠 → ……

轻轻一推，磁铁就自己越跑越快，同时线圈还在发电。这就是**永动机**，凭空造出能量，不可能。

> **楞次定律是能量守恒的结果**：你想让线圈发电，就得克服它的阻碍，付出力气。发出来的电能，就是你推磁铁做的功变来的。

这就是为什么自行车发电机灯一开，蹬起来明显更费劲。

## 第 4 步：写进公式

上一课的法拉第定律，加上楞次定律的方向，完整写法是：

> **感应电压 = −N × ΔΦ / Δt**

那个**负号**就是楞次定律：感应电压的方向，和磁通量的变化方向对着干。

## 揭晓谜题

磁铁往下掉，铜管的每一段都相当于一圈线圈，穿过它的磁通量在变化。铜导电很好，管壁里感应出电流（叫**涡流**）：

- 磁铁下方那段管子：磁通量在增加 → 推开磁铁（往上推）
- 磁铁上方那段管子：磁通量在减少 → 拉住磁铁（往上拉）

上下两边都在**往上托**，磁铁就慢下来。磁铁掉落的能量，最后变成铜管里涡流发的热。

换成塑料管，不导电，没有电流，磁铁就正常掉下去。

## 这和做硬件有什么关系

| 场景 | 和楞次定律的关系 |
|---|---|
| **电感"抗拒电流变化"** | 电流想变大，电感产生反向电压顶着；电流想变小，电感产生电压帮它维持。这是 §6 电感的核心 |
| **继电器 / 电机断电尖峰** | 电流突然断开，线圈拼命维持电流，产生**和原来方向相反**的高压尖峰。续流二极管反向并在线圈两端，给这股电流一条回路，把尖峰吃掉 |
| **电机反电动势** | 电机转起来，线圈在磁场里转，也在发电，这个电压和电源**对着干**。所以电机刚启动（还没转、没有反电动势）时电流最大，叫**堵转电流**，电源和驱动芯片要按这个最大值来选 |
| **变压器铁芯用一片片硅钢片叠起来** | 整块铁芯里会产生很大的涡流，白白发热。切成薄片、片间绝缘，涡流就小了 |
| **电磁炉** | 故意利用涡流：变化的磁场在锅底感应出涡流，锅自己发热 |
| **电磁刹车** | 高铁、过山车用磁铁和金属板产生涡流来减速，不需要接触 |

## 三句话总结

1. **感应电流总是阻碍磁通量的变化**：来拒去留
2. 这是**能量守恒**的结果：要发电就得克服阻碍做功
3. 电感抗拒电流变化、断电高压尖峰、电机反电动势、涡流，都是它的表现
