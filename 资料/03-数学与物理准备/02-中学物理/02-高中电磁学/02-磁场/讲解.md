# 磁场

**开场谜题：喇叭里只有一个磁铁和一圈导线，通的是电信号，为什么会发出声音？**（答案在最后）

## 第 1 步：磁铁也布置了"场"

和电荷一样，磁铁也在周围空间布置了一个场，叫**磁场**：

> **磁场 = 空间里每一点的一条规定：在这里放一个小磁针，它的 N 极会被转向哪个方向。**

小磁针静止时 N 极指的方向，就是该点**磁场的方向**。指南针能指北，就是因为地球本身有磁场。

## 第 2 步：把磁场画出来

画**磁感线**，读法：

- 在磁铁**外面**，从 **N 极出发，回到 S 极**
- 线**越密**，磁场**越强**（磁铁两极附近最密）
- 线从来不交叉

和电场线最大的不同：

> **磁感线是闭合的圈。** 在磁铁外面从 N 到 S，在磁铁里面再从 S 回到 N，没有起点，也没有终点。

原因是**没有单独的"磁荷"**：把磁铁掰成两半，得到的是两块各自带 N、S 极的小磁铁，永远分不出单独的 N 或单独的 S。电场线则不同，它从正电荷"出发"，到负电荷"结束"。

```text
        ╭──────→──────╮
        │             │
      ╭─┴─╮       ╭───┴╮
  ←── │ N │ ===== │ S  │ ←──      磁铁外：N → S
      ╰─┬─╯       ╰───┬╯          磁铁内：S → N
        │             │
        ╰──────←──────╯
```

## 第 3 步：电流会产生磁场（这是关键）

1820 年，奥斯特把一根通电导线放在小磁针旁边，**磁针转了**。

> **电流在周围产生磁场。** 磁铁不是磁场的唯一来源，**运动的电荷**（电流）也能产生磁场。

直导线周围的磁感线是**一圈圈套着导线的同心圆**。方向用**右手螺旋定则**（安培定则）判断：

- **直导线**：右手握住导线，**拇指指向电流方向**，四指弯曲的方向就是磁场方向
- **线圈**：右手握住线圈，**四指顺着电流绕的方向**，拇指指的那一端就是 **N 极**

把导线绕成线圈，每一圈的磁场叠加起来，线圈就像一根条形磁铁，这就是**电磁铁**。通电有磁性，断电磁性消失；圈数越多、电流越大，磁性越强。

## 第 4 步：磁场推电流

反过来也成立：**通电导线放进磁场里，会受到力**。

方向用**左手定则**判断：伸开左手，让**磁感线垂直穿过掌心**，**四指指向电流方向**，**拇指**指的就是导线受力的方向。

大小（导线和磁场垂直时）：

> **F = B × I × L**（力 = 磁感应强度 × 电流 × 导线长度）

例：B = 0.5 T，电流 2 A，磁场里的导线长 0.1 m：F = 0.5 × 2 × 0.1 = **0.1 N**。

电流反向，力也反向。**电机能转起来，靠的就是这个力。**

## 第 5 步：磁场有多强

**磁感应强度 B**，单位**特斯拉（T）**。

| 磁场来源 | 大约多强 |
|---|---|
| 地球磁场 | 50 µT（0.00005 T） |
| 冰箱贴 | 5 mT |
| 钕铁硼强磁铁表面 | 0.5 ~ 1 T |
| 医院核磁共振 | 1.5 ~ 3 T |

地球磁场很弱，只有几十 µT。所以手机里的电子罗盘很容易被旁边的磁铁、喇叭、大电流走线干扰。

## 第 6 步：和电场对比

| | 电场 | 磁场 |
|---|---|---|
| 谁产生 | 电荷 | 磁铁、**电流（运动的电荷）** |
| 作用在谁身上 | 所有电荷（静止的也受力） | 磁铁、**运动的电荷 / 电流**（静止电荷不受力） |
| 场线 | 从正出发，到负结束 | **闭合的圈** |
| 强度单位 | V/m | T |

## 揭晓谜题

喇叭的线圈放在磁铁的磁场里。电信号是一个忽正忽负、不断变化的电流，线圈受力 F = BIL，**电流方向一变，受力方向就跟着变**，线圈带着纸盆来回振动，推动空气，就发出了声音。电信号的波形，就变成了纸盆振动的波形。

## 这和做硬件有什么关系

| 场景 | 和磁场的关系 |
|---|---|
| **继电器** | 线圈通电变成电磁铁，把铁片吸过去，带动触点闭合 |
| **电机** | 磁场推电流（F = BIL），转起来 |
| **喇叭、蜂鸣器** | 电流变化 → 受力变化 → 振动出声 |
| **电感** | 一圈导线，电流在里面储存磁场能量（§6 会讲） |
| **霍尔传感器** | 测磁场强度，用来测转速、测位置、测电流 |
| **IMU 里的磁力计** | 测地球磁场，当电子罗盘用 |

## 三句话总结

1. **磁场**规定了小磁针在每一点往哪指；磁感线在磁铁外从 N 到 S，**是闭合的圈**
2. **电流产生磁场**：右手螺旋定则判断方向；线圈通电就是电磁铁
3. **磁场推电流**：左手定则判断方向，大小 F = BIL；这是电机和喇叭的原理
